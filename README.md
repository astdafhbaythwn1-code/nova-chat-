# Nova Chat — MVP تجريبي

واجهة دردشة عربية متجاوبة مستوحاة من تطبيقات المراسلة، وليست نسخة مطابقة من WhatsApp أو Telegram.

## الموجود في المشروع
- تسجيل حساب ودخول بكلمة مرور مشفّرة باستخدام bcrypt.
- جلسة دخول وواجهة دردشة ورسائل نصية أساسية.
- حسابات مميزة بطلب اشتراك (بدون دفع حقيقي).
- نجوم وهدايا تجريبية داخل التطبيق.
- طلبات توثيق ومراجعتها من لوحة الأدمن؛ الشارة محلية داخل Nova فقط.
- صلاحيات أدمن منفصلة، وإضافة نجوم للمستخدمين من لوحة التحكم.
- مثال C++ مستقل لحساب رصيد النجوم.

## التشغيل
يتطلب Node.js 18 أو أحدث:
1. فك الضغط وافتح مجلد المشروع.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. أنشئ hash لكلمة مرور الأدمن باستخدام الأمر:
   `node -e "const b=require('bcryptjs'); console.log(b.hashSync('CHANGE_THIS_PASSWORD', 12))"`
5. ضع الناتج في `ADMIN_PASSWORD_HASH` داخل `.env`، واختر `ADMIN_USERNAME`، وغيّر `SESSION_SECRET` إلى قيمة طويلة عشوائية.
6. نفّذ `npm start` وافتح `http://localhost:3000`.

## ملاحظات مهمة
- أول تشغيل ينشئ حساب الأدمن من متغيرات البيئة إذا لم يوجد حساب أدمن.
- بيانات النموذج تُحفظ في `data.json`. هذا مناسب للتجربة فقط، وليس لتطبيق إنتاجي متعدد المستخدمين.
- قبل النشر الحقيقي، استبدل تخزين JSON بقاعدة بيانات مثل PostgreSQL، وأضف حماية CSRF، تحديد معدل الطلبات، تحققًا أقوى من الروابط، وسجلات تدقيق ونسخًا احتياطية واختبارات.
- لا يوجد اتصال بخدمات Telegram أو WhatsApp، ولا يمكن لهذا المشروع منح شارات توثيق رسمية أو إنشاء يوزرات مميزة رسمية على تيليجرام.
- لا توجد مدفوعات حقيقية. عند إضافة الشراء، استخدم مزود دفع رسميًا وتحققًا من الإيصالات من الخادم، ولا تخزّن بيانات البطاقات.
- الأدمن يظهر له رصيد `∞` في الواجهة، ويتجاوز خصم النجوم عند إرسال الهدايا؛ لا تُخزَّن نجوم لا نهائية كرقم فعلي.
- لا تستخدم بيانات دخول حقيقية أو أسرارًا داخل الكود، ولا ترفع ملف `.env` إلى مستودع عام.

## تجميع مثال C++
